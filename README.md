# CryptChat – Secure Multi-Algorithm Messaging System

## 📌 About
A secure messaging system that encrypts communication
using multiple cryptographic algorithms. Built as part
of my Master's in Information Systems Security Management.

## 🛠️ Technologies Used
- Java
- AES, RSA, ECC, SHA Encryption
- Cryptography & Secure Key Exchange

## 🚀 Features
- End-to-end encrypted messaging
- Multiple encryption algorithm support
- Secure key exchange communication
- Hashing for message integrity

## 🎯 Purpose
This project was built to demonstrate real-world
application of cryptographic algorithms in a
secure messaging environment.
